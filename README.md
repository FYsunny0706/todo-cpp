# Todo-Cpp

一个用 C++17 写的命令行待办事项管理程序。支持任务的增删改查、按截止日期排序，以及数据的持久化保存。

## 功能

主菜单：

| 编号 | 功能 |
|---|---|
| 1 | 任务管理（进入子菜单） |
| 2 | 统计（进入子菜单） |
| 3 | 立即保存 |
| 0 | 退出 |

任务管理：

| 编号 | 功能 |
|---|---|
| 1 | 查看全部任务 |
| 2 | 添加任务（标题 / 描述 / 截止日期 / 分类 / 重要度） |
| 3 | 标记完成 |
| 4 | 取消标记 |
| 5 | 删除任务 |
| 6 | 修改任务（标题 / 描述 / 截止日期 / 分类 / 重要度） |
| 7 | 按截止日期升序排序（无期限的排在最后） |
| 8 | 批量标记（全部标记完成 / 全部取消标记 / 按编号标记 / 按编号取消） |
| 9 | 批量删除（按编号删除 / 清空已完成 / 删除所有任务） |
| 10 | 查找任务（关键词 / 分类 / 状态组合查询） |
| 0 | 返回 |

统计：

| 编号 | 功能 |
|---|---|
| 1 | 完成率 |
| 2 | 逾期任务 |
| 3 | 分类分布（字符柱状图） |
| 4 | 重要任务分布 |
| 0 | 返回 |

程序启动时自动读取 `data/tasks.txt`，每次修改后自动保存，退出不会丢数据。

## 环境要求

- Windows
- g++ 11.5 或更高（支持 C++17）
- g++ 与 gdb 需要在系统 PATH 中（把 MinGW 的 `bin` 目录加进 PATH）

## 编译与运行

**方式一：VS Code**

1. 用 VS Code 打开项目根目录
2. `Ctrl+Shift+B` 编译
3. `F5` 运行

**方式二：命令行**

```powershell
g++ -std=c++17 -Wall -Wextra -Iinclude app/*.cpp src/*.cpp -o build/todo.exe
.\build\todo.exe
```

⚠️ 必须在项目根目录运行，因为数据文件用的是相对路径 `data/tasks.txt`。

## 数据文件格式

第一行是版本标记 `v2`，之后每行一条任务，用 `|` 分隔七个字段：

```
v2
1|买牛奶|明天要喝|0|2026-11-10|生活|0
2|写作业||0||学业|1
```

- 完成状态：`0` 未完成，`1` 已完成
- 截止日期：`YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM`（24 小时制，时分必须补零），留空表示没有期限
- 分类：学业 / 生活 / 工作 / 其他
- 重要度：`0` 否，`1` 是
- 字段内若出现 `\`、`|` 或换行，会写成 `\\`、`\|`、`\n`

## 设计要点

- **写入用临时文件 + 改名**，写到一半出问题不会损坏原文件
- **字段转义**，标题里出现 `|` 也不会破坏格式
- **加载全有或全无**，任何一行格式错误就整体拒绝，不会导入一半
- **输入校验**，标题非空、日期必须是真实存在的日期
- **每次修改后自动存盘**，不依赖用户记得按保存
- **批量删除按编号从大到小进行**，避免编号重排后删错任务
- **删除所有任务需要二次确认**
